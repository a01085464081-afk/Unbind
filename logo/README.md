# Unbind 로고 사용 가이드

## 콘셉트
**뽑힌 플러그**: 터미널 커서(`_`)에서 뽑혀 나간 플러그. "포트를 비운다"는 앱의 동작을 표현해요.

## 파일 (`final/`)
| 파일 | 용도 |
|---|---|
| `unbind-symbol.svg` | 기본 로고 (검정) |
| `unbind-symbol-white.svg` | 어두운 배경용 (흰색) |
| `unbind-symbol-small.svg` | 작은 크기용 (24px 이하). 다리와 커서를 굵게 그림 |
| `Unbind.icon/` | 앱 아이콘 (흑백 평면, 유리 효과 끔). Icon Composer로 열어 수정 가능 |
| `unbind-appicon.svg` | 평면 앱 아이콘 이미지 (문서·웹용) |
| `menubar-free.png` / `menubar-busy.png` | 메뉴바 아이콘 (비어 있음 = 뽑힘, 사용 중 = 꽂힘) |

## 색상
| 이름 | HEX | 쓰임 |
|---|---|---|
| 블랙 | `#0A0A0B` ~ `#2C2C2E` | 앱 아이콘 배경 (위가 밝은 세로 그라데이션) |
| 화이트 | `#FFFFFF` | 어두운 배경 위 로고 |

## 규칙
- **최소 크기**: 24px 이하에서는 작은 크기용 파일 사용
- **여백**: 로고 둘레에 커서 두께만큼 비워 두기
- **배경**: 흰색/밝은 회색에는 검정이나 컬러, 어두운 배경에는 흰색 사용
- **하지 말 것**: 플러그와 커서의 간격 바꾸기, 늘리거나 기울이기, 그림자·테두리 추가, 색 넣기 (흑백 유지)

## 수정 후 다시 만들기
`final/*.svg`를 고친 뒤 아래 한 줄로 아이콘을 다시 만들고 앱을 빌드해요.
```sh
~/Unbind/logo/make-icons.sh && ~/Unbind/build.sh
```
